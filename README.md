# The Inbox Edit

Static portfolio. GitHub Pages hosting is free.

## Publish

1. On GitHub, click **New repository**. Name it, choose **Public**, then click **Create repository**.
2. Push this folder to the `main` branch.
3. In the repository, open **Settings → Pages**. Under **Build and deployment**, set **Source** to **GitHub Actions**.

A push to `main` builds the site and publishes it.
